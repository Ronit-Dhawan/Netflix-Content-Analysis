# 🎬 Netflix Content Analysis

## 📌 Project Overview
This project explores Netflix's content library using Python and Exploratory Data Analysis (EDA). The objective is to identify patterns in content distribution, release trends, ratings, countries, durations, and content categories to generate meaningful business insights and recommendations.


---

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

---


## 📈 Analysis Performed
- Data Cleaning and Preprocessing
- Missing Value Analysis
- Movie vs TV Show Distribution
- Content Category Analysis (`listed_in`)
- Country-wise Content Analysis
- Release Year Trend Analysis
- Rating Distribution Analysis
- Duration Analysis
- Business Insights and Recommendations
