# 🎬 Netflix Content Analysis

## 📌 Project Overview
This project explores Netflix's content library using Python and Exploratory Data Analysis (EDA). The objective is to identify patterns in content distribution, release trends, ratings, countries, durations, and content categories to generate meaningful business insights and recommendations.

---

## 🎯 Objectives
- Analyze the distribution of Movies and TV Shows.
- Identify the most common content categories.
- Analyze country-wise content availability.
- Study content release trends over the years.
- Explore ratings and duration patterns.
- Generate business insights based on the analysis.

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## 📊 Dataset
The dataset contains the following attributes:
- show_id
- type
- title
- director
- cast
- country
- date_added
- release_year
- rating
- duration
- listed_in
- description

---

## 📈 Analysis Performed
- Data Cleaning and Preprocessing
- Missing Value Analysis
- Movie vs TV Show Distribution
- Content Category Analysis (`listed_in`)
- Country-wise Content Analysis
- Release Year Trend Analysis
- Rating Distribution Analysis
- Duration Analysis
- Business Insights and Recommendations

---

## 💡 Key Insights
- Movies dominate Netflix's content library.
- Drama and International Movies are among the most common content categories.
- The United States and India contribute a significant portion of Netflix's catalog.
- Netflix has expanded its content library rapidly in recent years.
- Most movies have a runtime between 90 and 120 minutes.
- TV Shows have increased steadily over time, indicating a growing focus on serialized content.

---

## 🚀 Business Recommendations
- Increase investment in high-performing content categories.
- Expand regional and international original content.
- Continue investing in TV Shows to improve user engagement.
- Strengthen country-specific content strategies.
- Use data-driven insights to optimize future content acquisition.
